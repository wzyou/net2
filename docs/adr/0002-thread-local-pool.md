# ADR-0002: 采用 Thread-Local 无锁资源池

- 状态：Accepted
- 日期：2026-08-08

## 背景
高并发代理场景下，频繁 malloc/free 与跨线程共享池会造成碎片、锁竞争与缓存失配。

## 决策
采用 Thread-Per-Core + Thread-Local 资源池：
- Buffer 池按核心独立维护。
- Upstream Keep-Alive 连接池按核心独立维护。
- 路由/配置按快照只读访问并通过 RCU 风格热更新。

## 结果
- 正向：借还路径 O(1) 且无锁；降低尾延迟波动。
- 正向：提升 CPU cache 局部性与可预测性。
- 代价：跨核心资源复用降低，需要更精细的容量规划。

## 约束
- 禁止在热路径引入跨线程共享可变池。
- 任何跨核数据访问都必须有明确所有权和同步证明。
