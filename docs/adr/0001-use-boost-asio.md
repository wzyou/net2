# ADR-0001: 采用 Boost.Asio + C++20 协程

- 状态：Accepted
- 日期：2026-08-08

## 背景
网关需要在高并发连接场景下保持低延迟与高可维护性。传统回调式异步模型可读性差，线程池 + 锁的共享模型在热点路径存在争用与抖动。

## 决策
采用 Boost.Asio Proactor 模型，并以 C++20 协程 (`asio::awaitable<T>`) 组织异步控制流。

## 结果
- 正向：线性代码结构、减少回调嵌套、提升可维护性。
- 正向：与 Thread-Per-Core 模型结合，便于同核闭环。
- 代价：协程帧管理复杂度上升；团队需统一协程编码规范。

## 备选方案
- 回调风格 Asio：可行但维护成本高。
- 其他运行时：迁移成本与生态适配成本较高。
