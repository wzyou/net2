# netp2

高性能 C++20 协程异步网关项目。

## 架构文档入口
- AI 约束与全局护栏：`.github/copilot-instructions.md`
- 模块化架构文档：`docs/architecture/`
- 架构决策记录（ADR）：`docs/adr/`

详细的架构约束与模块边界请参考 `docs/architecture/` 目录下的所有规范文档。

## 文档治理规则
- 架构文档是代码的一部分，代码变更需要同步更新对应文档。
- 任何跨线程共享可变状态的设计变更，必须先更新架构文档并通过审查。
- 重大架构演进（协议、拓扑、配置热更新机制）必须新增 ADR。
